Privacy Policy

Last updated: 19 October 2026

Wiki Roulette Upload is a private tool operated by the owner of the Wiki Roulette YouTube channel. Its only purpose is to upload and schedule the owner's own videos to the owner's own YouTube channel using the YouTube Data API.

What data the tool uses

  • An OAuth access/refresh token for the owner's YouTube account, granted by the owner.
  • The owner's own video files and their titles, descriptions and settings.

What it does not do

  • It does not collect, store or share data of any other person.
  • It does not sell data, show ads or track visitors. This website sets no cookies.

Storage and security

The token is stored only as an encrypted GitHub Actions secret in the owner's repository and is used only to call the YouTube Data API. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
