Sound effects in this folder come from Kenney's free audio packs (Interface Sounds, Impact Sounds, UI Audio,
RPG Audio, Casino Audio, Sci-Fi Sounds, Digital Audio): https://kenney.nl/assets — CC0 1.0 (public domain),
see Kenney-License.txt. Converted to 48 kHz mono WAV and trimmed of silence. Credit is optional; we add "Sound effects: Kenney (kenney.nl), CC0".
Names = cue types in score_cine.mjs (pop_1.wav … boom_1.wav). Set "sfx": "synth" in an episode to use only the synthesized sounds.
